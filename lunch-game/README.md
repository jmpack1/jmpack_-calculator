# 🍱 JM 런치 배틀

JMPACK 점심 메뉴를 카카오톡 단톡방에서 다 같이 정하는 참여형 웹 게임입니다.
설치나 회원가입 없이 **단톡방에 올린 링크 하나로** 들어와서 3분 안에 끝납니다.

## 게임 흐름 (최대 5명, 차 1대 기준)

| 단계 | 내용 | 시간 |
|---|---|---|
| 대기실 | 링크 입장 → 닉네임·캐릭터 선택. 6번째 사람부터는 관전 | - |
| ① 컨디션 | 🔥든든 / 🥗가볍게 / 🌶️매운 / 🍲국물 / 😴아무거나 | 15초 |
| ② 하트 투표 | 메뉴 카테고리 6개에 하트 3개 분배 | 30초 |
| ③ 거부권 | 상위 4개 중 1개 거부, 또는 양보 (양보하면 룰렛 표 1.5배) | 15초 |
| ④ 식당 투표 | 남은 카테고리 중 식당 후보 2~4곳에 투표 | 20초 |
| ⑤ 룰렛 | 득표율로 룰렛. 60% 이상 득표 시 바로 확정 | 7초 |
| 결과 | 카카오맵 길찾기, 단톡방 결과 공유, 한 판 더 | - |

- 모든 사람이 투표를 마치면 타이머를 기다리지 않고 다음 단계로 넘어갑니다.
- **최근 7일 안에 간 식당**은 후보에서 자동으로 빠집니다.
- 매일 같은 링크를 쓰면 **그날의 방**으로 자동 연결됩니다. 단톡방 공지에 링크를 고정해 두세요.

## 식당 데이터

| 구분 | 설명 |
|---|---|
| ⭐ 단골 | 장수촌순대국, 미미반점, 이조명가옛날육계장, 너베기두루치기삼겹살, 송가네부대찌개, 오늘도돈까스, 아부지국밥, 방일해장국 |
| 👍 추천 | 웹 검색으로 찾은 가산면 일대 식당 (`restaurants.js`에서 수정) |
| 🆕 카카오맵 | 카카오 키를 설정하면 회사 기준 **차로 15분 반경** 음식점을 자동으로 수집 (7일마다 갱신) |
| ➕ 직접 추가 | 게임 안의 "식당 관리" 화면에서 누구나 추가하거나 끌 수 있음 |

> 차량 이동 시간은 직선거리로 추정한 값입니다 (거리 km × 1.5 + 2분).

## 설치·배포 방법

### 0) 바로 체험 (설정 없음)
`index.html`을 열면 **체험 모드**로 동작합니다. 한 기기 안에서만 동기화되고, 🤖 테스트 봇으로 혼자서도 플레이해 볼 수 있습니다.

```bash
cd lunch-game && python3 -m http.server 8000   # http://localhost:8000
```

### 1) 여러 폰 실시간 참여: Firebase (무료)
1. https://console.firebase.google.com 에서 프로젝트 생성
2. **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 싱가포르 `asia-southeast1` 권장)
3. **규칙** 탭에 `database.rules.json` 내용을 붙여넣고 게시
4. **프로젝트 설정 → 내 앱 → 웹 앱(</>) 추가** 후 표시되는 `firebaseConfig`를 `config.js`의 `FIREBASE:`에 붙여넣기
   ```js
   FIREBASE: { apiKey: "...", authDomain: "...", databaseURL: "https://...firebasedatabase.app", projectId: "..." },
   ```

### 2) 인터넷에 올리기: GitHub Pages (추천, 자동 배포)
1. GitHub 저장소 → **Settings → Pages → Source**를 **GitHub Actions**로 변경
2. `main` 브랜치의 `lunch-game/`이 바뀔 때마다 자동으로 배포됩니다.
3. 주소: **https://jmpack1.github.io/jmpack_-calculator/** ← 단톡방 공지에 고정

### 2-1) (대안) Firebase Hosting
```bash
npm install -g firebase-tools
firebase login
cd lunch-game
firebase use --add            # 위에서 만든 프로젝트 선택
firebase deploy               # → https://<프로젝트>.web.app 주소가 생김
```
이 주소를 단톡방 공지에 올려두면 됩니다.

### 3) 카카오톡 공유 + 카카오맵 맛집 자동 수집
1. https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
2. **앱 키 → JavaScript 키**를 복사해 `config.js`의 `KAKAO_JS_KEY`에 입력
3. **플랫폼 → Web → 사이트 도메인**에 배포 주소 등록 (예: `https://<프로젝트>.web.app`)
4. **카카오맵** 사용 설정 활성화 (제품 설정 → 카카오맵)

키가 없어도 "단톡방에 공유" 버튼은 동작합니다. 공유창을 열거나 내용을 클립보드에 복사해 붙여넣을 수 있게 해줍니다.

## 보안 참고
사내용 간단 버전이라 링크를 아는 사람은 누구나 투표 데이터를 읽고 쓸 수 있습니다. 개인정보는 저장하지 않으며 닉네임과 투표 내용만 저장합니다.
외부 공개가 걱정되면 Firebase 익명 인증과 규칙을 추가해 강화할 수 있습니다.

## 파일 구성
- `index.html` / `style.css`: 화면
- `app.js`: 게임 로직 (단계 진행, 집계, 룰렛, 공유, 카카오맵 수집)
- `config.js`: Firebase·카카오 키, 회사 주소, 최대 인원
- `restaurants.js`: 단골·추천 식당 목록
